Flux de test personnalisés
Un flux = une suite ordonnée de scénarios IA simulant un parcours utilisateur complet.
Créez autant de flux que nécessaire — positif, négatif, sécurité — sauvegardez et relancez à tout moment.
Comment ça fonctionne : L'IA génère d'abord tous les scénarios individuels. Vous composez ensuite des flux en ordonnant ces scénarios. Les données sont partagées entre étapes — l'email de l'inscription est automatiquement réutilisé au login.
